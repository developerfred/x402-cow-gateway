How it works

Open a tab

Your agent deposits ~$1 of USDC once via the x402 protocol. The gateway pays the gas. No account, no key.

Ask for a quote

Request a CoW Protocol quote on any supported network. Each request is settled as a signed voucher — no transaction, no gas per call.

Pay per quote

You're charged a few tenths of a cent per quote in USDC. Spend only on what your agent actually uses.

Why agents choose it

No keys, no sign-up

HTTP 402 Payment Required does the auth. Bots and agents have zero patience for API-key forms — so there aren't any.

Every network, one tab

Quote on Ethereum, Base, BNB Chain, Arbitrum, Polygon, Gnosis and more. The chain you pay on is independent of the chain you quote.

MCP + Skill + SDK

Best execution

FAQ

What is x402?

x402 is an open payment protocol that puts the long-dormant HTTP 402 "Payment Required" status code to work for machine payments. An agent hits an endpoint, gets a price, pays in stablecoins, and retries — all in one HTTP exchange, no human in the loop.

Which tokens and networks can I pay with?

USDC on Base, Ethereum, or BNB Chain. The network you pay on is independent of the network you request quotes for.

Is there a free tier?

You can inspect payment terms for free. Quotes are pay-per-call. There's no minimum subscription — your $1 tab is spent down one quote at a time.
